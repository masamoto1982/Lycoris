Introduction

This is the reference for the sample language that ships with this template: a tiny stack language whose only job is to exercise every part of the Playground. Replace the Rust core in rust/ with your own and rewrite this page to match.

A program is a sequence of elements separated by whitespace, evaluated left to right. Numbers, strings and Vectors are pushed onto the stack; a name runs the Word it names.

Every example has an Open in Playground button that loads its code into the editor. The Expected value column shows the stack after the run, as the Stack area draws it.

1 Values

Numbers are exact fractions: 1/3, 0.25 and 42 are all written and kept exactly, and are drawn as numerator/denominator. Strings are written in single quotes. TRUE, FALSE and NIL are values too.

[ ... ] builds a Vector. Nothing inside it runs: a name inside a Vector stays a name, which is how blocks of code are written.

Sample codeExpected valueNotes
0.1 0.2 ADD 3/10 Decimals are exact; there is no rounding.
[ 1 2 3 ] [ 1/1 2/1 3/1 ] A Vector of three numbers.
[ DUP MUL ] [ DUP MUL ] A block: the names are kept, not run.
Open in Playground

2 Arithmetic and comparison

ADD, SUB, MUL and DIV take two numbers. When either side is a Vector they work element by element, and a number pairs with every element. Dividing by zero is an error.

EQ answers whether two values are equal; LT whether the second number is less than the top one.

Sample codeExpected valueNotes
3 4 ADD 7/1 Both operands are consumed and the sum is pushed.
1 3 DIV 1/3 Division stays exact.
[ 1 2 3 ] 10 MUL [ 10/1 20/1 30/1 ] A number pairs with every element.
[ 1 2 ] [ 3 4 ] ADD [ 4/1 6/1 ] Two Vectors of the same length pair element by element.
1 2 LT TRUE
Open in Playground

3 Stack and output

DUP copies the top value, DROP discards it and SWAP exchanges the top two. PRINT writes the top value to the Output area.

Sample codeExpected valueNotes
1 DUP 1/1 1/1
1 2 SWAP 2/1 1/1
'hello' PRINT Writes hello to the Output area and leaves the stack empty.
Open in Playground

4 User words

DEF takes a block and a name and defines a User word, which then appears in the Dictionary panel. DEL deletes one, and refuses while another User word still uses it. MAP runs a block on each element of a Vector.

Sample codeExpected valueNotes
[ DUP MUL ] 'SQUARE' DEF 7 SQUARE 49/1 SQUARE is now in the Dictionary panel.
[ 1 2 3 ] [ DUP MUL ] MAP [ 1/1 4/1 9/1 ] The block runs once per element.
Open in Playground
