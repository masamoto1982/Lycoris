はじめに

このテンプレートに同梱しているサンプル言語のリファレンスです。Playground のすべての機能を動かすためだけの、小さなスタック言語です。rust/ の Rust コアを自分の言語に差し替えたら、このページもそれに合わせて書き換えてください。

プログラムは空白で区切った要素の並びで、左から順に評価されます。数値・文字列・Vector はスタックに積まれ、名前はそのワードを実行します。

各例の Playground で開く ボタンでコードをエディタに読み込めます。期待値 列は、実行後のスタックを Stack エリアの表示どおりに示します。

1 値

数値は正確な分数です。1/3、0.25、42 はいずれも丸めずに保持され、分子/分母 の形で表示されます。文字列はシングルクォートで囲みます。TRUE、FALSE、NIL も値です。

[ ... ] は Vector を作ります。中身は実行されず、名前は名前のまま残ります。コードのブロックはこの形で書きます。

サンプルコード期待値備考
0.1 0.2 ADD 3/10 小数も正確で、丸め誤差はありません。
[ 1 2 3 ] [ 1/1 2/1 3/1 ] 3 つの数値の Vector。
[ DUP MUL ] [ DUP MUL ] ブロック。名前は実行されずに残ります。
Playground で開く

2 算術と比較

ADD・SUB・MUL・DIV は 2 つの数値を取ります。どちらかが Vector なら要素ごとに計算し、数値は各要素と組になります。ゼロ除算はエラーです。

EQ は 2 つの値が等しいか、LT は 2 番目の数値が先頭より小さいかを返します。

サンプルコード期待値備考
3 4 ADD 7/1 2 つのオペランドを消費して和を積みます。
1 3 DIV 1/3 除算も正確です。
[ 1 2 3 ] 10 MUL [ 10/1 20/1 30/1 ] 数値は各要素と組になります。
[ 1 2 ] [ 3 4 ] ADD [ 4/1 6/1 ] 同じ長さの Vector 同士は要素ごとに計算します。
1 2 LT TRUE
Playground で開く

3 スタックと出力

DUP は先頭の値を複製し、DROP は捨て、SWAP は上の 2 つを入れ替えます。PRINT は先頭の値を Output エリアに書き出します。

サンプルコード期待値備考
1 DUP 1/1 1/1
1 2 SWAP 2/1 1/1
'hello' PRINT Output エリアに hello と表示され、スタックは空になります。
Playground で開く

4 ユーザーワード

DEF はブロックと名前を取ってユーザーワードを定義し、Dictionary パネルに表示します。DEL は削除しますが、他のユーザーワードが使っている間は拒否します。MAP は Vector の各要素にブロックを実行します。

サンプルコード期待値備考
[ DUP MUL ] 'SQUARE' DEF 7 SQUARE 49/1 SQUARE が Dictionary パネルに追加されます。
[ 1 2 3 ] [ DUP MUL ] MAP [ 1/1 4/1 9/1 ] ブロックは要素ごとに 1 回実行されます。
Playground で開く
